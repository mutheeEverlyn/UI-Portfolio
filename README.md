# UI-Portfolio


## Overview
This UI Portfolio is a personal portfolio website designed to showcase expertise in UI/UX design and web development. The project provides a clean, elegant, and responsive interface that highlights a designer’s skills, services, and previous work.

## Features
- **Responsive Navbar** with interactive links
- **Hero Section** introducing the designer
- **Biography Section** with personal details
- **Services Section** outlining provided skills
- **Skills Breakdown** displaying proficiency levels
- **Portfolio Gallery** showcasing past projects
- **Footer** with contact details and social links
- **Action Icons** for easy navigation

## Technologies Used
- **HTML5** – Structure of the website
- **CSS3** – Styling and layout design
- **Font Awesome** – Icon integration
- **Google Fonts** – Custom typography
- **CSS Animations & Transitions** – Enhancing interactivity
